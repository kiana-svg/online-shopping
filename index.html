Course Shopping System
This project is a simple course shopping system. The user enters the name of the course they are looking for. The program checks whether the course exists in the available products list. If the course is valid, it is added to the user's orders and the total order price is displayed. If the course does not exist, an error message is shown. To test it, enter one of these course names:
javascript
pyton
c++
java
You can also enter an invalid name such as html to test the error handling.
